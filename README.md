This project contains a Jupyter Notebook focused on learning how to import and use the NumPy library in Python. It introduces the basics of numerical computing and demonstrates how NumPy simplifies working with arrays and mathematical operations.

File Included
3040assigmentone (2) (4).ipynb – Main notebook containing code, explanations, and exercises.
Objectives

This assignment aims to:

Learn how to install and import NumPy
Understand the purpose of NumPy in Python
Create and manipulate NumPy arrays
Perform basic mathematical operations
Explore simple array-based problem solving
Requirements

To run this project, make sure you have:

Python 3.x
Jupyter Notebook or JupyterLab
NumPy installed

Install NumPy using:

pip install numpy
How to Run
Clone or download this repository
Open the notebook in Jupyter Notebook or JupyterLab
Run each cell step-by-step to view outputs
Topics Covered
Importing NumPy (import numpy as np)
Creating arrays
Array operations
Basic arithmetic with NumPy
Introduction to numerical computing
